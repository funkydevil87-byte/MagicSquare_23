## 4. 아키텍처 변경 요약

### 4.1 의존 방향 (그룹 3 이후)

```text
Screen (app.py)
  → Boundary (magic_square_boundary, result_formatter, exceptions)
    → Control (magic_square_solver, solve_partial_magic_square, exceptions)
      → Entity (two_cell_solver, locator, finder, validator)
```

- **Boundary**는 Entity를 import하지 않음 (`UnsolvableDomainError` catch 제거).
- **Control**이 `UnsolvableDomainError` → `SolveUnsolvableError`로 변환.
- **Boundary**가 `SolveUnsolvableError` → `UnsolvableError`로 매핑.

### 4.2 책임 분리

| 컴포넌트 | 책임 |
|----------|------|
| `TwoCellSolver` | complete + validate 단일 시도 · `list[int] \| None` |
| `SolvePartialMagicSquare` | Attempt 1(small-first) → Attempt 2(reverse) 순서 |
| `MagicSquareSolver` | Control orchestration · Domain 예외 경계 |
| `ResultFormatter` | Boundary 표시 문자열 · `int[6]` SSOT (`to_solution_vector`) |
| `MagicSquareApp` | Grid I/O · Boundary 호출 · Formatter 위임 |
