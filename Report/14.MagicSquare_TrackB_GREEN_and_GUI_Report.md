## 6. 구현 요약

### 6.1 Entity — `MagicSquareValidator`

- 완성 격자: `0` 없음 · `1..16` 각 1회 · 10선 합 `MAGIC_CONSTANT(34)`
- `complete_grid()`: 부분 격자에 두 빈칸 채운 **복사본** 반환 (입력 불변)

### 6.2 Control — `SolvePartialMagicSquare`

```
locate blanks → find missing (small, large)
  → Attempt 1: small→첫빈칸, large→둘째빈칸 → validate
  → 실패 시 Attempt 2: reverse
  → 둘 다 실패 → UnsolvableDomainError
```

### 6.3 Boundary — `MagicSquareBoundary.solve()`

| 경로 | 동작 |
|------|------|
| 검증 실패 | `FailureResult` 조기 반환 (Track A GREEN 유지) |
| 풀이 성공 | `list[int]` 길이 6 반환 |
| 풀이 불가 | `UnsolvableError` (`UNSOLVABLE` + PRD 고정 메시지) |

### 6.4 GUI — `boundary/screen/app.py`

```powershell
pip install -e .
python -m magicsquare.boundary.screen.app
```

- 4×4 Entry 격자 · Solve/Clear · G1·완성 샘플 로드
- Boundary API 호출 · 성공/INVALID_SIZE/UNSOLVABLE 표시
