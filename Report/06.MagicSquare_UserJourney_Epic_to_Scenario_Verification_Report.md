## 1. 작성 목적

본 보고서는 Magic Square 4×4 TDD Practice 프로젝트에서 **Epic → User Journey → User Story → Technical Scenario** 흐름을 Level 1~4로 정의한 뒤, Level 5에서 **일관성·커버리지·구현 준비도**를 검증한 세션 결과를 기록한다.

본 세션에서는 **구현 코드·테스트 코드·신규 기능 파일을 작성하지 않았다.** 설계·요구·검증 산출물만 채팅으로 출력하고, 본 Report·Transcript로 Export한다.

## 2. 세션 산출물 요약 (Level 1~4)

### 2.1 Level 1 — Epic

| 항목 | 내용 |
|------|------|
| Epic Title | 불변식 기반 사고 훈련 시스템 구축 |
| Business Goal | 4×4 부분 격자(빈칸 2개) 입력 → `int[6]` 또는 Error Code로 **결정적** 해결·실패 |
| Learning Goal | 불변식 설계, Dual-Track TDD, I/O 계약, Concept→Invariant→Contract→Test 추적 |
| Key Invariants | `INV-D-*`, `INV-C-*`, `INV-S-*` (GRID_SIZE, MAX_VALUE, MAGIC_CONSTANT) |
| Candidate User Stories | C-US-01~C-US-15 (Level 2 분해용) |

### 2.2 Level 2 — User Journey (5 Stage)

| Stage | 목적 | 핵심 산출 |
|-------|------|-----------|
| 1 Problem Recognition | 표면 요구 vs 불변식 훈련 재정의 | Pain Point, Related Invariant |
| 2 Contract Definition | IC/OC/Error Contract 선행 고정 | Input·Output·Error 표, INV-C-GATE |
| 3 Domain Separation | BlankFinder, MissingNumberFinder, Validator, Solver 분리 | Responsibility Separation |
| 4 Dual-Track TDD | Boundary Track A + Domain Track B | UI RED / Logic RED / GREEN / REFACTOR |
| 5 Regression Protection | edge·입력 오류·UNSOLVABLE·출력 형식 | Regression Test Target |

**Journey → User Story 후보:** US-01~US-05 (핵심), US-08~US-16 (회귀·통합·선택)

### 2.3 Level 3 — User Stories

| Story ID | 이름 | Layer | Protected INV/Contract |
|----------|------|-------|------------------------|
| US-01 | 입력 검증 | Boundary | IC-01~07, INV-C-GATE, INV-C-ERROR-SCHEMA |
| US-02 | 빈칸 좌표 탐색 | Domain | INV-D-EMPTY, INV-C-EMPTY-SCAN |
| US-03 | 누락 숫자 탐색 | Domain | INV-D-MISSING, INV-D-RANGE, INV-D-UNIQUE |
| US-04 | 마방진 검증 | Domain | INV-D-COMPLETE, INV-D-LINE-SUM, INV-D-MAGIC |
| US-05 | 두 가지 조합 시도 | Domain + Control/Boundary | INV-D-ORDER, OC-01~11, UNSOLVABLE |

**Acceptance Criteria:** AC-US01-01~08, AC-US02-01~06, AC-US03-01~06, AC-US04-01~09, AC-US05-01~13 — 모두 **Given-When-Then·측정 가능** 문장.
