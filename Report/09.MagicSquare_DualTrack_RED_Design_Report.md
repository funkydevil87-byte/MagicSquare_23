## 1. 작성 목적

본 보고서는 **Dual-Track UI + Logic TDD** 관점에서 FR-01~FR-05 전 범위의 **RED 테스트 설계표**를 확정한 세션 결과를 기록한다. 본 세션에서는 구현 코드·pytest 코드·스켈레톤·파일 저장을 수행하지 않았으며, **설계표 텍스트(채팅 산출)** 만 확정한다.

## 3. 프로젝트 계약 (설계 SSOT)

| 항목 | 고정 값 |
|------|---------|
| 입력 | 4×4 `int[][]`, `0`=빈칸(정확히 2), 값 `0`∪`1..16`, 0 제외 중복 금지 |
| 출력 | `int[6]` = `[r1,c1,n1,r2,c2,n2]`, 좌표 **1-index** |
| 마방 상수 | **M = 34** (`MagicConstant` SSOT) |
| 검증 순서 | null → size → empty count → range → duplicate (short-circuit) |
| Boundary invalid | **Failure envelope** 반환 (generic `Exception` 아님) |
| Domain 진입 | invalid 시 `SolvePartialMagicSquare.execute` **0회** (U-FLOW-02) |
| Logic Track | Entity/Control 단위, **Domain Mock 금지** |

---

## 4. Failure envelope · E-Code (세션 SSOT)

| E-Code | 순서 | message (exact, RED 설계 SSOT) | PRD AC 매핑 |
|--------|:----:|--------------------------------|-------------|
| E003 | 1 | `Input matrix must not be null.` | AC-FR01-03 |
| E001 | 2 | `Grid must be 4x4.` | AC-FR01-04, -05 |
| E002 | 3 | `Exactly two blank cells (0) required.` | AC-FR01-06 |
| E004 | 4 | `Each value must be 0 or in 1..16.` | AC-FR01-07 |
| E005 | 5 | `Non-zero values must be unique.` | AC-FR01-08 |

**Envelope 형태:** `{ success: false, error: { code, message }, data: null }`

> **Decision Needed (DQ-RED-01):** PRD v1.1 §13은 Boundary 실패 시 **예외 throw**를 확정. 본 RED 설계표는 세션 지시의 **Failure envelope**를 따름. GREEN 전 SSOT 단일화 필요.

## 6. Track A — Boundary / UI Contract RED 설계 요약

### 6.1 U-IN (입력 검증) — 12건

| Test ID | 검증 | Domain `execute` |
|---------|------|:----------------:|
| U-IN-01 | `matrix=null` → E003 | 0회 |
| U-IN-02a~e | size ≠ 4×4 (3×4, 4×3, 5×5, `[]`, jagged) → E001 | 0회 |
| U-IN-03a~b | 빈칸 0개·3개 → E002 | 0회 |
| U-IN-04a~b | `-1`, `17` → E004 | 0회 |
| U-IN-05 | 비영 중복 → E005 | 0회 |

### 6.2 U-OUT (출력 계약) — 2건

| Test ID | Given | Then |
|---------|-------|------|
| U-OUT-01 | G1 + `execute` stub | 성공 배열 길이 6 |
| U-OUT-02 | G1 + `execute` stub | r,c ∈ [1,4], 1-index |

> U-OUT만 `execute` test double 허용. Domain 로직 Mock 금지.

### 6.3 U-FLOW (흐름 격리) — 5건

| Test ID | 검증 |
|---------|------|
| U-FLOW-02a~e | invalid 입력별 `execute.call_count == 0` + 해당 E envelope |

**Expected RED Failure (공통):** `ModuleNotFoundError`, `AttributeError`, `AssertionError` — `InputValidator` / `UIBoundary` / envelope 미구현.
