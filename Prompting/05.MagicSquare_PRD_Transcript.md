Input:
- 4x4 integer matrix int[][]
- 0은 빈칸, 정확히 2개
- 유효 값: 0 또는 1~16
- 0 제외 중복 금지
- 첫 번째 빈칸: row-major 순서로 처음 발견되는 0

Output:
- int[6] = [r1, c1, n1, r2, c2, n2]
- 좌표 1-index
- n1, n2는 누락된 두 숫자

Solving Order:
- Attempt 1: 작은 누락 숫자 → 첫 빈칸, 큰 누락 숫자 → 둘째 빈칸
- Attempt 2: Attempt 1 실패 시 반대 조합
- 두 조합 모두 실패: 실패 정책 하나로 확정 (미정 금지)
