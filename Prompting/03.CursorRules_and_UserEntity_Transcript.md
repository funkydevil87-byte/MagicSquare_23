### User (Interactive Prompt)

다음 요구사항을 만족하도록 MagicSquare Python 프로젝트용 Cursor Rule을 설계하고, `.cursorrules` 파일을 생성한 뒤 ECB 패턴으로 `User` 엔티티를 구현해줘.

조건:
- Python 3.13.13
- PEP8
- type hints 필수
- pytest + AAA 패턴
- ECB 아키텍처(boundary/control/entity)
- Dual-Track TDD
- print() 디버깅 금지
- 테스트 약화 금지
- RED 없이 구현 금지

작업 순서:
1) Cursor Rule 설계 방식 설명: `.cursorrules` vs `.cursor/rules/*.mdc` 선택 가이드 및 프로젝트 기준 분할 전략 제안
2) `.cursorrules` YAML 뼈대 작성: 최상위 키 `project, code_style, architecture, tdd_rules, testing, forbidden, file_structure, ai_behavior`만 포함
3) `tdd_rules` 섹션을 단계별로 채우기: red/green/refactor 규칙 명시
4) 빈 섹션을 모두 채운 `.cursorrules` 전체를 출력한 뒤, 프로젝트 루트에 실제 파일로 생성하기
5) `.cursorrules`를 읽고 ECB 패턴으로 `User` 엔티티 클래스를 `entity` 레이어에 작성하기
   - 타입힌트 필수
   - Google docstring (모든 public 메서드)
   - pytest 테스트 파일도 함께 생성(AAA 패턴)
   - RED→GREEN 순서 준수
6) `python -m pytest`로 테스트가 통과하는지 확인하기

ECB 폴더 구조 요구:
